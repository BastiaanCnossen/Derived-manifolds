# Chapter files

This directory intentionally contains no placeholder chapter files. A chapter
is added only after its deliberation dossier and detailed outline have been
reviewed. Filenames should remain neutral, for example `01.tex`, so that a
provisional title does not become an accidental organizational commitment.

The order, number, and boundaries of chapters remain revisable. In particular,
a manuscript chapter need not correspond to exactly one seminar meeting if the
writing process reveals a better division of the material.
