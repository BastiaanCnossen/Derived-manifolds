# Supplementary chapters

These chapters contain substantial material which is not part of the default
fourteen-talk route and is not currently included by `main.tex`.

1. `pardon-derived-regularity.tex` gives the full account of Pardon's
   regular-locus and parameter-thickening approach. Talk 13 uses only a short
   comparison with this argument.
2. `logarithmic-degeneration.tex` develops the outlook on degenerating domains,
   logarithmic smooth geometry, and the boundary between representability and
   virtual-class constructions.

Both files use the notation, bibliography, and cross-reference conventions of
the main manuscript.
