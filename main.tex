\chapter*{About these notes}
\addcontentsline{toc}{chapter}{About these notes}

These notes are being developed in preparation for a semester of MIGOS on
derived manifolds. The intended audience includes first-year PhD students with
backgrounds in homotopy theory, algebraic geometry, differential geometry, and
analysis. We will emphasize geometric questions and concrete examples while
using modern homotopy-theoretic language when it clarifies the mathematics.

The chapter structure is intentionally not fixed in advance. Each chapter will
be added only after a separate deliberation phase has identified its role,
dependencies, main example, principal result, and realistic route for a live
seminar talk. Consequently, the eventual chapters need not correspond
one-to-one with the talks in the current draft program.
