# MIGOS 2026/27: Derived manifolds

This is the git repository for the weekly reading seminar of the CRC "Generalized Motivic Methods in Geometry" in Regensburg. The seminar is organized by Bastiaan Cnossen and Sil Linskens. It contains the program for the MIGOS WiSe2026/27. It also contains lecture notes for the seminar generated by Codex.
